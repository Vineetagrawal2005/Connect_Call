# ConnectCall — Demo Recording Script

Needs TWO devices/emulators (Device A + Device B), both with the release APK installed and internet access.

1. **Login (Device A):** open app → splash → Login → log in as user one (register first if needed) → land on Home with greeting.
2. **Login (Device B):** open app → log in as user two → land on Home.
3. **Contact list (Device A):** show the Home/Contacts list — point out user two with the green online dot, avatar initial, and the 📞 / 🎥 icons.
4. **Start video call (Device A):** tap the 🎥 video icon on user two's row → allow camera + microphone when asked → outgoing call screen appears.
5. **Accept (Device B):** show the real incoming-call screen → tap Accept → both sides join.
6. **In-call controls:** mute/unmute mic, toggle camera off/on, switch camera (Device A); show speaker toggle on an audio call if time permits.
7. **End call:** end from either side → both return to the app.
8. **Call history:** open the Calls tab → newest record on top with the other user's name, "Video • Completed • duration" → repeat view on the second device.
9. (Optional, needs a re-record or second take) **Missed call:** call from A, Decline/timeout on B → show the red "Missed" indicator in history.
